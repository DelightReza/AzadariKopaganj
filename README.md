# Azadari Kopaganj

Official zero-API, zero-login video archive, live broadcast portal, Progressive Web App (PWA), and Capacitor Android app for the **Azadari Kopaganj** YouTube channel (`UCyCIC43pbujKarf1irIjtrA`).

- **YouTube Channel**: <https://www.youtube.com/channel/UCyCIC43pbujKarf1irIjtrA>
- **Android Package ID**: `com.azadari.kopaganj`

---

## Features

- **No API Keys or Login Required**: Populates the entire channel history (since September 2018) from static JSON manifests generated by `update_feed.py` (`config.json`, `assets/livenow.json`, and monthly `assets/{YYYY}/{MM}/videos.json` & `post.json`).
- **Four Core Sections**:
  - **Home**: Featured active Live Stream banner/player (when live), Recent Videos, and Popular Videos.
  - **Live**: Dedicated active live stream view and archive of past live streams.
  - **Videos**: Full searchable video & Shorts archive with year/month filters and topic chips (`Jashn`, `Majlis`, `Nauha`, `Qaseeda`).
  - **Posts**: Community posts & announcements with multi-image carousel viewer, fullscreen image lightbox, and linked video playback.
- **Custom Inbuilt Theatre Player (`InbuiltVideoPlayer`)**:
  - Custom YouTube IFrame controls (play/pause, ±10s skip, scrubbing preview, playback speed, quality selector, volume, previous/next queue navigation).
  - Unobstructed ad overlay so YouTube's official Skip button works natively, with a compact `AD PLAYING` indicator and isolated ad mute control.
  - **Pinned Mobile Theatre**: Keeps the active 16:9 player anchored below the header on portrait mobile/tablet screens while scrolling video details and the Up Next queue underneath, and uses a sticky watch column on desktop.
  - **Smart Fullscreen Orientation**: Automatically locks 16:9 videos and live streams to landscape in fullscreen (including a rotated mobile web fallback where OS orientation lock is restricted) while keeping vertical `9:16` Shorts in portrait.
- **Hash Routing & State Preservation**: Shareable hash routes (`#/`, `#/live`, `#/videos`, `#/posts`, `#/watch/<id>`, `#/watch/live`) preserve active playback, tabs, filters, search queries, and lightbox Back navigation across refreshes.
- **Offline-Ready PWA**: Caches app shell, manifests (`NetworkFirst`), and YouTube thumbnails (`CacheFirst`) via `vite-plugin-pwa`.
- **Android APK Background Sync & Notifications**:
  - Checks notification permissions on APK launch and prompts the user to enable notifications (opening Android Notification Settings if previously blocked).
  - Runs an hourly Android `WorkManager` background worker (`ConfigSyncWorker`) even when the app is closed, fetching `config.json`, `assets/livenow.json`, and recent monthly feeds from GitHub Raw.
  - Sends deduplicated notifications across dedicated channels (`azadari_live_alerts`, `azadari_video_alerts`, `azadari_post_alerts`) with deep-link routing straight to Live Watch, the new video, or Community Posts on tap.

## Architecture & Data Flow

| Component | Purpose |
| --- | --- |
| `update_feed.py` | Zero-API Python scraper using YouTube InnerTube + RSS to update `config.json`, `assets/livenow.json`, and `assets/{YYYY}/{MM}/{videos,post}.json`. |
| `src/services/archiveService.ts` | Loads manifests from `./` on Web/PWA or `raw.githubusercontent.com/DelightReza/AzadariKopaganj/main/` in the Android APK (falling back to bundled assets). |
| `src/services/notificationSyncService.ts` | Manages APK startup permission checks, native `AzadariBackgroundSync` bridge calls, snapshot synchronization, and foreground alerts. |
| `src/utils/appRouting.ts` | Parses and serializes hash routes and filter query parameters. |
| `src/utils/archiveLogic.ts` | Video/post filtering, topic matching, Short detection, feed diffing (`detectFeedUpdates`), and uncropped community post image helpers. |
| `android-native/java/com/azadari/kopaganj/` | Native Android `ConfigSyncWorker`, `AzadariNotificationHelper`, `AzadariBackgroundSyncPlugin`, and `MainActivity`. |
| `configure_android_app.py` | Configures the generated Capacitor `android/` project with app metadata, adaptive icons, monochrome notification drawable (`ic_stat_azadari`), manifest permissions, WorkManager dependency, native Java sources, and release signing config. |

## Local Development

### Prerequisites

- Node.js `22+` and npm
- Python `3.12+` (only needed to run `update_feed.py` or `configure_android_app.py`; `pillow` is optional for mipmap generation)

### Commands

```bash
# Install dependencies
npm install

# Start development server on http://localhost:3000
npm run dev

# Run TypeScript type check
npm run lint

# Run unit tests
npm test

# Build production web bundle + copy config.json & assets/ into dist/
npm run build

# Refresh YouTube archive & live status manifests
python3 update_feed.py
```

## Android APK & GitHub Actions Workflows

The repository includes three automated workflows under `.github/workflows/`:

1. **`update_videos.yml` (`Update Azadari Kopaganj YouTube Feed & Manifests`)**
   - Runs every 4 hours (and manually via `workflow_dispatch`) to execute `python3 update_feed.py` and commit updated `config.json` and `assets/` files.
2. **`deploy_pages.yml` (`Deploy Azadari Kopaganj to GitHub Pages`)**
   - Syncs manifests, builds `dist/`, and deploys to GitHub Pages on pushes to `main` or after the feed updater finishes.
3. **`build_android_apk.yml` (`Build Signed Android APK (Capacitor)`)**
   - Builds the web bundle, initializes/syncs Capacitor Android (`npx cap add android && npx cap sync android`), applies `configure_android_app.py`, compiles release APK/AAB via Gradle, runs `zipalign` + `apksigner` (V1/V2/V3) + signature verification, uploads build artifacts, and publishes a GitHub Release (`v<version_name>`).

### Required GitHub Secrets for Signed APK Builds

Configure the following secrets in **Repository Settings → Secrets and variables → Actions**:

| Secret Name | Description |
| --- | --- |
| `ANDROID_KEYSTORE_BASE64` | Base64-encoded release `.jks` / `.keystore` file |
| `ANDROID_KEYSTORE_PASSWORD` | Keystore password |
| `ANDROID_KEY_ALIAS` | Signing key alias |
| `ANDROID_KEY_PASSWORD` | Key password (defaults to `ANDROID_KEYSTORE_PASSWORD` if omitted) |
